🙋 프로그래머스 SQL 고득점 Kit : 평균 일일 대여 요금 구하기 풀이 (MySQL)

  <br/>

<center><a href="https://school.programmers.co.kr/learn/courses/30/lessons/151136" style = 'font-size : 1.18rem; font-weight : 900'>SQL 고득점 Kit : 평균 일일 대여 요금 구하기</a></center>

  <br/>

## 📌 **문제 요약**

`CAR_RENTAL_COMPANY_CAR` 테이블에서 `SUV` 차량의 평균 일일 대여 요금을 조회하는 문제이다.

- 평균은 소수 첫째 자리에서 반올림
- 컬럼명은 `AVERAGE_FEE`

  <br/>

## ✅ **풀이**

- `SELECT` (평균 일일 요금의 반올림 값)
- `FROM` CAR_RENTAL_COMPANY_CAR
- `WHERE` (자동차 종류가 'SUV') ;

  🔽

- `SELECT` ROUND(AVG(일일요금))
- `FROM` CAR_RENTAL_COMPANY_CAR
- `WHERE` 차종류 = 'SUV';

  <br/>

## ⌨️ **제출 SQL**

```sql

SELECT
    ROUND(AVG(DAILY_FEE)) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV';

```

<br/>

## 💡 **풀이 포인트**

- `ROUND()`로 소수 첫 번째 자리에서 반올림
